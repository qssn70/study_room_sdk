# 极简自习室 UI 设计文档（方案二：全核心居中布局）

## 1. 全局视觉规范
- 视觉风格与毛玻璃材质同方案一。

## 2. 竖屏布局 (宽 390px, 高 844px)
采用 Flex 垂直居中布局：
- **核心居中区 (屏幕正中央)**：
  - 作为一个整体垂直居中。从上到下依次为：预设栏 -> 番茄钟圆环 -> 控制按钮 -> 今日目标卡片。
  - 组件之间有固定间距，视觉重心完美落在屏幕中央。
- **底部区 (贴底，有边距)**：
  - 成员抽屉：默认隐藏，悬浮于底部 Dock 栏正上方。
  - 底部 Dock 栏：毛玻璃胶囊容器，四周保留 24px 边距。包含“统计”、“背景音”、“成员”按钮。

## 3. 横屏布局 (宽 844px, 高 390px)
采用左右分栏布局：
- **左侧 (Flex 1.4)**：背景透出，垂直居中放置预设栏、番茄钟、控制按钮。
- **右侧 (Flex 1.0)**：整体毛玻璃面板。
  - 顶部：常驻成员列表（横向排列，隐藏滚动条）。
  - 中部：今日目标卡片、背景音选择器。
  - 底部：私密数据统计与柱状图。
