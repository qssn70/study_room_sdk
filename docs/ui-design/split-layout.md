# 极简自习室 UI 设计文档（方案一：上下分离布局）

## 1. 全局视觉规范
- 背景：全屏暗色背景图 + rgba(0,0,0,0.25) 遮罩。
- 毛玻璃材质：背景色 rgba(255,255,255,0.08)，边框 rgba(255,255,255,0.15)，模糊度 blur(20px)。
- 主题色：专注绿 #81C784，休息橙 #FFB74D。

## 2. 竖屏布局 (宽 390px, 高 844px)
采用 Flex 上下分离布局：
- **上半部 (垂直居中)**：
  - 包含：预设栏、番茄钟圆环、控制按钮（结束/暂停/跳过）。
  - 此区域紧密排列，作为视觉焦点悬浮于屏幕偏上位置。
- **下半部 (贴底，有边距)**：
  - 成员抽屉：默认隐藏，点击 Dock 栏“成员”按钮后，在 Dock 栏上方弹出（毛玻璃容器，横向滑动头像+昵称列表，隐藏滚动条）。
  - 今日目标卡片：毛玻璃圆角矩形，显示任务名和番茄进度。
  - 底部 Dock 栏：毛玻璃胶囊状容器，四周保留 24px 边距（不贴边）。内含“统计”、“背景音”、“成员”三个操作项。

## 3. 横屏布局 (宽 844px, 高 390px)
采用左右分栏布局：
- **左侧 (Flex 1.4)**：背景透出，垂直居中放置预设栏、番茄钟（缩小至160px）、控制按钮。
- **右侧 (Flex 1.0)**：整体毛玻璃面板。
  - 顶部：常驻成员列表（横向排列，头像+昵称，隐藏滚动条）。
  - 中部：今日目标卡片、背景音选择器。
  - 底部：私密数据统计与柱状图。
