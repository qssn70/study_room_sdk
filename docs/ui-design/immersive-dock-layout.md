# 极简自习室 UI 设计文档（方案三：沉浸式贴底布局，推荐）

## 1. 全局视觉规范
- 视觉风格与毛玻璃材质同前。
- 强调系统级沉浸感。

## 2. 竖屏布局 (宽 390px, 高 844px)
- **核心居中区**：
  - 与方案二一致，预设栏、番茄钟、控制按钮、今日目标卡片作为一个整体在屏幕垂直居中。
- **底部区 (沉浸式贴底)**：
  - 外层容器去除底部 padding。
  - 成员抽屉：默认隐藏，通过 `bottom: calc(100% + 16px)` 精准悬浮于贴底 Dock 栏的正上方。
  - 底部 Dock 栏：
    - 使用负 margin (如 -24px) 向左右拉伸，贴紧屏幕左右边缘。
    - 贴紧屏幕底部（无下方 padding，仅保留模拟手机安全区的厚度）。
    - 顶部大圆角 (24px)，底部直角。内含“统计”、“背景音”、“成员”按钮。

## 3. 横屏布局 (宽 844px, 高 390px)
采用左右分栏布局：
- **左侧 (Flex 1.4)**：背景透出，垂直居中放置预设栏、番茄钟（缩小至160px）、控制按钮。
- **右侧 (Flex 1.0)**：整体毛玻璃面板。
  - 顶部：常驻成员列表（横向滑动，隐藏滚动条，小尺寸头像+昵称）。
  - 中部：今日目标卡片、背景音选择胶囊。
  - 底部：私密数据统计（专注时长、番茄数、连续天数）与柱状图占位。

## 4. 开发重点提示 (给 GPT)
1. 横竖屏切换需使用响应式逻辑判断。
2. 竖屏 Dock 栏贴底需利用负 Margin 突破父级容器 padding。
3. 成员列表需全面隐藏滚动条（Web端 `scrollbar-width: none` 及 `::-webkit-scrollbar { display: none; }`）。
4. 毛玻璃效果需使用 `backdrop-filter: blur()`。
